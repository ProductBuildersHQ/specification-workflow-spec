## [v0.3.0] - 2026-08-15

### Highlights

- Loader-enforced per-spec template/rubric provenance: a SpecSource declares which workflow owns a spec's template/rubric (or "local"), and a declared source that doesn't actually provide the file is a load-time error
- Layered rubric schema (Class/Blocking/Evaluation, JudgeInstructions) extended onto structured-evaluation's RubricSet, wired through the library and regenerated JSON schemas
- Hardened aws-one-way-door and aws-two-way-door workflows: normative enterprise contract templates/rubrics, symmetric optional deepening (MRD or OpportunitySpec both feed PRD synthesis in both doors), and a loader cycle guard covering both extends and explicit spec sources
- prism-sync: a nested-module tool that copies roadmap-domain templates/rubrics from prism-roadmap with provenance headers and a -check drift mode, keeping prism-roadmap out of the library's module graph
- Catalog registries for pipelines, loops, and integrations, with a cross-reference test validating pipelines against workflows/integrations/spec-types and loops against everything

- Provenance-aware loader: SpecSource provenance, strict library-wide resolution guarantee (every declared spec resolves, optional included), and a cycle guard threading the resolution chain through both extends links and explicit spec sources ([`7058a75`](https://github.com/ProductBuildersHQ/specification-workflow-spec/commit/7058a75))
- tools/prism-sync: manifest-driven copy of roadmap-domain content with provenance headers stamped from debug.ReadBuildInfo(), -check drift mode for CI, own go.mod so prism-roadmap never enters the library module graph ([`149f32b`](https://github.com/ProductBuildersHQ/specification-workflow-spec/commit/149f32b))

## [v0.2.0] - 2026-08-02

### Highlights

- Canonical home for workflow definitions: all 24 default workflows (stage-based, methodology-based, big-tech syntheses, v2mom, pbhq-lite) are embedded and loadable as Go structs with no filesystem access
- Breaking: pkg/profile renamed to pkg/workflow (Profile -> Workflow, inner Workflow field -> Execution); pkg/rubricdef removed in favor of structured-evaluation's rubric.RubricSet

### Added

- Add embedded workflow registry and composable loaders (embedded, file, fs.FS, chain, resolving with extends inheritance and cycle detection) ([`47aba7b`](https://github.com/ProductBuildersHQ/specification-workflow-spec/commit/47aba7b))
- Add default workflow definition library with 24 methodologies imported from visionspec ([`99d1b6b`](https://github.com/ProductBuildersHQ/specification-workflow-spec/commit/99d1b6b))
- Add Content field to Template for filesystem-free template loading ([`d0c3f40`](https://github.com/ProductBuildersHQ/specification-workflow-spec/commit/d0c3f40))
- Parse methodology YAML shorthand and grouped artifacts; add Artifact type and Methodology.Source ([`73b0b14`](https://github.com/ProductBuildersHQ/specification-workflow-spec/commit/73b0b14))
